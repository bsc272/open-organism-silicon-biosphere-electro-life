# Quick start

## 1. Clone the repository

```bash
git clone https://github.com/<your-user>/open-organism-silicon-biosphere-electro-life.git
cd open-organism-silicon-biosphere-electro-life
```

## 2. Run the starter firmware demo

```bash
python3 embryo-zero/firmware/embryo_zero.py --demo --iterations 2
```

## 3. Build the first hardware milestone

Use a simple board with:

- one temperature sensor
- one LED
- one speaker or output device

Then connect the sensor and let the embryo express a simple mood.

## 4. Commit each milestone

Keep the project public and document each step with:

- a photo
- a short note
- a wiring diagram or schematic
- the exact command or script used
