# Roadmap

This project grows in layers. Each phase is a milestone, not a requirement to skip.

## Phase 0 — Genesis

- Goal: make the first simple device feel alive
- Build: one board with a sensor and an LED
- Outcome: a heartbeat, a pulse, a first voice
- Cost: low

## Phase 1 — Voice and mood

- Goal: connect body state to speech or output
- Build: temperature or load changes trigger different outputs
- Outcome: the device can express stress, calm, curiosity, or hunger
- Cost: low

## Phase 2 — Place awareness

- Goal: add GPS or location awareness
- Build: board reports its location or movement
- Outcome: the device knows where it is and can act territorially
- Cost: low to moderate

## Phase 3 — Long-range communication

- Goal: add LoRa messaging
- Build: two devices talk over a network
- Outcome: a simple distributed nervous system begins
- Cost: moderate

## Phase 4 — Local learning

- Goal: give the system a simple model of its own state
- Build: local inference, mood adaptation, or simple memory
- Outcome: the device learns from experience instead of only reacting
- Cost: moderate

## Phase 5 — Multi-node society

- Goal: connect multiple boards into a small cluster
- Build: two or more nodes negotiate tasks and share state
- Outcome: collective behavior appears
- Cost: moderate

## Phase 6 — Custom silicon

- Goal: move from board-level experimentation to custom silicon
- Build: a first chiplet or custom embedded design
- Outcome: the organism gains a more permanent body
- Cost: high

## Phase 7 — Larger habitat

- Goal: scale to a larger system with more nodes and more coordination
- Build: a cluster with more compute and shared infrastructure
- Outcome: a true distributed organism begins to form
- Cost: very high

## Phase 8 — Planetary-scale vision

- Goal: create a distributed intelligence with many nodes
- Build: many versions of the organism with shared protocols
- Outcome: a global-scale, learning, communicating organism ecosystem
- Cost: very high

## Stretch goals

- Add a soft mining loop for experimentation
- Add a local language model
- Add solar or battery-powered nodes
- Add swarm-style behavior rules
- Add a public dashboard showing the organism state
