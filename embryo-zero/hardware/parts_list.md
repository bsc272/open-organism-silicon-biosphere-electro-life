# Beginner parts list

A simple first build can be assembled with very basic parts.

## Minimum parts

- 1x microcontroller or single-board computer
  - Raspberry Pi Zero 2 W or Raspberry Pi 4/5
  - or ESP32-S3 for a more embedded route
- 1x temperature sensor
  - DHT22 or DS18B20
- 1x LED
- 1x speaker or headphone output
- 1x breadboard and jumper wires
- 1x USB power supply

## Optional later upgrades

- GPS module
- LoRa module
- microphone
- OLED display
- rechargeable battery pack
